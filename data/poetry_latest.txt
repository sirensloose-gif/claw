# 推荐诗歌：《云》 - 唐·来鹄

## 原文
```
千形万象竟还空，
映水藏山片复重。
无限旱苗枯欲尽，
悠悠闲处作奇峰。
```

## 逐句释义
1. **千形万象竟还空** - 云朵变幻出千万种形态，最终却化为一片虚空
2. **映水藏山片复重** - 它倒映在水面，又隐藏在山间，时而单薄时而厚重
3. **无限旱苗枯欲尽** - 大地上无数禾苗因干旱即将枯死
4. **悠悠闲处作奇峰** - 它却悠闲地在天边聚成奇特的山峰形状

## 整体白话翻译
天空中的云朵变幻万千形态，最终却化为虚无一片。它时而倒映在水面，时而藏身于山间，时而单薄时而厚重。正当大地上的禾苗因干旱即将全部枯死时，这云却悠闲地在天边堆成奇特的山峰形状。

## 创作背景故事
来鹄是唐末诗人，一生仕途不顺，曾多次应试不第。此诗创作于晚唐社会动荡时期，诗人以云为喻，暗指当时统治阶层的虚伪与不作为。诗中的“旱苗”象征受苦的百姓，“悠悠闲处作奇峰”的云则暗喻高高在上、不关心民生疾苦的官僚阶层。诗人借自然现象抒发对社会现实的深刻批判。

## 艺术特色分析
1. **对比手法精妙**：将“旱苗枯欲尽”的紧急与“悠悠闲处”的悠闲形成强烈对比，增强批判力度
2. **意象双关**：云既是自然现象，又象征特定社会阶层，一物双喻
3. **结构严谨**：前两句写云的形态变化，后两句转向社会寓意，层层递进
4. **语言清新**：用简单自然的语言表达深刻思想，不事雕琢却意境深远
5. **讽刺含蓄**：不直接指责，而是通过客观描写让读者自己体会其中深意

## 现代启示
这首诗虽写于千年之前，但对当今社会仍有深刻启示：
1. **权力与责任的关系**：掌握资源者（如诗中的云）有责任服务大众（如旱苗），而不应只顾自我表现
2. **形式与实质的思考**：华美的外表（奇峰）不如实际贡献（滋润旱苗）重要
3. **社会公正的呼唤**：提醒人们关注弱势群体的生存状态
4. **自我反思的镜子**：每个人都可以思考自己是否像那朵云，只注重形象而不做实事

这首诗以小见大，用常见的自然现象引发对社会问题的思考，展现了古典诗歌“言有尽而意无穷”的美学特质，是唐末讽喻诗中的佳作。
