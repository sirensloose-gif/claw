# 周易第十五卦：谦卦（地山谦）

---

## 一、卦名与卦象

```
┌─────────────────────┐
│  ☷ 上卦：坤（地）    │
│  ─ ─  ─ ─  ─ ─      │
│  ─ ─  ─ ─  ─ ─      │
│  ─ ─  ─ ─  ─ ─      │
│  ☶ 下卦：艮（山）    │
│  ─ ─  ─ ─  ─ ─      │
│  ━━━  ━━━  ━━━      │
│  ━━━  ━━━  ━━━      │
└─────────────────────┘
     上坤下艮 = 地山谦
```

> **卦名**：谦（qiān）
> **卦象**：**地山谦** —— 上卦为坤（地），下卦为艮（山）
> **卦德**：内刚外柔，内止外顺

**卦象寓意**：高山本应高耸于大地之上，却甘居于大地之下。这象征着一个有实力、有德行的人，反而把自己放在低处，不自满、不炫耀——这便是**谦**的精髓。

> 🌟 **重要地位**：谦卦是《周易》六十四卦中**唯一一个六爻皆吉**的卦（上六虽有"征邑国"之意，但总体仍属吉），被历代易学家推为"至德之卦"。

---

## 二、卦辞

### 📜 原文

> **谦：亨，君子有终。**

### 📖 白话解释

**谦卦：亨通。君子能善始善终，取得好的结果。**

| 关键词 | 解释 |
|-------|------|
| **亨** | 亨通，顺利。谦虚之人，天道助之，故万事亨通 |
| **君子** | 有德行、有才能的人 |
| **有终** | 能够善终、有好结果。不是中途放弃，而是坚持到底 |

**核心要义**：谦虚不是软弱无能，而是一种**真正的力量**。具备实力却依然保持谦卑的人，能够亨通无阻，并且善始善终。

---

## 三、六爻爻辞详解

谦卦六爻自下而上，描绘了**谦德由内而外、由个人到社会**的层层展开。

---

### 🔹 初六（最下爻·阴爻）

> **原文：谦谦君子，用涉大川，吉。**

**白话解释**：谦虚而又谦虚的君子，即使渡过大河险难，也是吉祥的。

| 要素 | 解析 |
|------|------|
| **谦谦** | 谦之又谦，双重谦逊，指谦虚到了极点 |
| **用涉大川** | 能够克服重大困难险阻（"涉大川"是《易经》常用比喻） |
| **吉** | 结果吉祥 |

**启示**：处于谦卦的最底层，地位最低、资历最浅。正因如此，更应该**谦虚谨慎**。一个人在起点时若能保持最低姿态、最谦虚的心态，反而无所畏惧，可以安全渡过任何难关。

---

### 🔹 六二（第二爻·阴爻）

> **原文：鸣谦，贞吉。**

**白话解释**：谦虚的美德得到众人的共鸣和赞美，坚守正道则吉祥。

| 要素 | 解析 |
|------|------|
| **鸣谦** | "鸣"是名声远播。谦虚之名已经为人所知，为人所赞叹 |
| **贞吉** | 守持正固则吉祥 |

**启示**：到了第二爻，你的谦虚已经不再只是内在品质，而是**外在能被他人感知到的名声**。但要注意：名声远播时更要守住本心，不要让谦虚变成做作或沽名钓誉。

---

### 🔹 九三（第三爻·阳爻）⭐ 全卦唯一阳爻

> **原文：劳谦，君子有终，吉。**

**白话解释**：勤劳而谦虚的君子，能够善始善终，吉祥。

| 要素 | 解析 |
|------|------|
| **劳** | 勤劳、有功劳、付出辛劳 |
| **劳谦** | 有大功于人却依然谦虚，不居功自傲 |
| **君子有终** | 君子能善终，得到好的结局 |
| **吉** | 吉祥 |

**启示**：九三是谦卦**唯一的阳爻**，象征一个卦的核心力量——一个真正有能力、有功劳的人，却**毫不自傲**，依然勤勉谦逊。这正是谦卦的核心精神。古语说"有功不居，善莫大焉"，功成而谦，才能真正走到最后。

> ⚡ 这是全卦的**主爻（卦主）**，是谦卦精神的集中体现。

---

### 🔹 六四（第四爻·阴爻）

> **原文：无不利，撝（huī）谦。**

**白话解释**：没有任何不顺利的，发挥谦虚的美德。

| 要素 | 解析 |
|------|------|
| **无不利** | 无所不顺，万事顺利 |
| **撝谦** | "撝"是发挥、推广。发挥、传播谦虚的美德 |

**启示**：进入上卦，位高权重，处于**辅佐之位**。此时不仅自己谦虚，还要**将谦虚之德推广开来**，带动周围的人共同谦逊。居高位而谦虚，能发挥最大的正面影响力。

---

### 🔹 六五（第五爻·阴爻·君位）

> **原文：不富以其邻，利用侵伐，无不利。**

**白话解释**：不以财富骄人，能够与邻国（或身边人）共享；此时利用征伐（纠正不正之事），无往不利。

| 要素 | 解析 |
|------|------|
| **不富以其邻** | 自己不以富贵骄人，不与邻人争夺财富 |
| **利用侵伐** | 对于不服从谦德的势力，可以进行征伐，以正不正 |
| **无不利** | 无所不利 |

**启示**：六五处君主之位，是**谦德的最高境界**。作为领导者，以谦卑治天下，自己不骄奢，与臣民共利。但谦虚**不等于软弱**——对于违背正义的事物，仍有果断行动的魄力。**真正的谦，是柔中有刚。**

---

### 🔹 上六（最上爻·阴爻）

> **原文：鸣谦，利用行师，征邑国。**

**白话解释**：谦虚之名远扬天下，此时利于出兵征讨，讨伐那些不服谦德的邦邑小国。

| 要素 | 解析 |
|------|------|
| **鸣谦** | 谦虚之名已远播天下 |
| **利用行师** | 利于兴兵动武 |
| **征邑国** | 征讨附近不服从的邦邑、小国 |

**启示**：谦卦到了最上爻，达到了**谦德的极致**。谦虚的名声已经远播天下，此时若有不义之人、不服教化之邦，以正义之师征讨，乃是替天行道。**谦不是一味退让，当仁不让时也要有行动的力量。
