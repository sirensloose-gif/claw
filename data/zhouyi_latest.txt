# 周易第8卦：比卦（比 ☵ 比 ☵）

---

## 一、卦名与卦象

```
卦名：比（bǐ）

卦象结构：
   ☵ 坎（水） ← 上卦
   ☷ 坤（地） ← 下卦

  · · ·  ☷  ─ 上六
  — — —  ☷  ─ 九五
  · · ·  ☷  ─ 六四
  · · ·  ☵  ─ 六三
  · · ·  ☵  ─ 六二
  · · ·  ☵  ─ 初六

  整体卦画（自下而上）：☷☵ → ⚖

卦序：第8卦
卦性：一阳（九五）居尊位，五阴亲附于下
卦象：坎水在上、坤地在下 → 水流于大地之上，润泽万物
      亦可理解为水与地相互亲近、彼此依附 → 象"亲密""依附""联合"
```

**卦名释义：**
"比"有**亲比、依附、亲近、联合、择善而从**之意。此卦象征人与人之间建立亲密关系、以诚信结交、择明君而从的智慧。

---

## 二、卦辞

### 📜 原文

> **比：吉。原筮，元永贞，无咎。不宁方来，后夫凶。**

### 🗣️ 白话解释

**比卦是吉祥的。** 但这种吉祥不是随意而来的——**推究原初，以诚心重新占问，如果能秉持正道、始终不渝，则没有灾祸。**

那些不安分的人纷纷前来亲比、归附；**但是迟疑不决、后来的人会有凶险。**

**关键提示：**
- **原筮**：不是反复占问，而是回归根本、以至诚之心重新审视
- **元永贞**：以"元"（大的根本）为主，"永"（长久）为用，"贞"（正道）为则——即：**以至诚为根本，以长久为追求，以正道为准则**
- **后夫凶**：犹豫拖延，错过时机，反而招来凶险

## 三、六爻爻辞（自下而上）

---

### 初六：有孚比之，无咎。有孚盈缶，终来有他，吉。

**白话解释：**
初六居卦之始，以**诚信**去亲比于上，没有灾祸。诚信就像装满水的陶罐（"缶"是粗朴的陶器），满溢而出，这种至诚最终会吸引别人主动来归附，是吉祥的。

**象曰：比之初六，有他吉也。**

| 要素 | 内容 |
|------|------|
| 爻位 | 初位，阴柔之始 |
| 关键词 | **诚信、至诚、吸引** |
| 智慧 | 亲比的基础是真诚。不必刻意追求，以诚待人，自然有人来投 |
| 现代启示 | 做事先修己身，以诚信立身，吸引力会自然形成 |

---

### 六二：比之自内，贞吉。

**白话解释：**
六二以阴居阴，**发自内心**地亲比于上位的九五。坚守正道，是吉祥的。

**象曰：比之自内，不自失也。**

| 要素 | 内容 |
|------|------|
| 爻位 | 二位，阴爻居阴位，得正 |
| 关键词 | **内心、自省、由内而外** |
| 智慧 | 亲比要出于真心，而非外在逢迎。内在修养好了，关系自然稳固 |
| 现代启示 | 与人交往、与组织结合，发自内心地认同，而非功利性攀附 |

---

### 六三：比之匪人。

**白话解释：**
六三阴爻居阳位，不正；又处坎卦之极，接近上卦。**所亲比的不是正人，而是不当之人。** 此爻警示危险。

**象曰：比之匪人，不亦伤乎？**

| 要素 | 内容 |
|------|------|
| 爻位 | 三爻，阴居阳位，不正；处坎险之极 |
| 关键词 | **选错人、盲从、危险** |
| 智慧 | 亲比对象很重要。如果所依附的是品行不端的人，不仅自己受损，还可能被牵连 |
| 现代启示 | 择友、择业、择伴时要慎重考察。**跟对人，比跟对事更重要。** |

---

### 六四：外比之，贞吉。

**白话解释：**
六四阴爻居阴位，得正，亲比于上卦的九五（阳爻在尊位）。**向外求贤君而亲附之，坚守正道，吉祥。**

**象曰：外比于贤，以从上也。**

| 要素 | 内容 |
|------|------|
| 爻位 | 四爻，阴居阴位，得正 |
| 关键词 | **外比、择善而从、贤者** |
| 智慧 | 在适当的位置，向外亲近贤能之人、追随好的领导者，以正道行事 |
| 现代启示 | 在职场或社会中，主动向有德有才的人学习
