# 📖 周易第十七卦 · 随卦（泽雷随）

## 一、卦名与卦象

| 项目 | 内容 |
|------|------|
| **卦名** | 随（Suí） |
| **卦象** | ☱ 上卦为**兑**（泽）　☳ 下卦为**震**（雷） |
| **全称** | **泽雷随** |
| **卦象图示** | 上：**— —**（阴） |
| | 中：**————**（阳） |

| | 上：**————**（阳） |
| | 中：**— —**（阴） |
| | 下：**————**（阳） ← 下卦震 |

**卦象释义：** 泽中有雷，雷本在天上，今伏于大泽之中，如同春雷初动，万物随之而生。泽润万物，万物顺随其德，故曰"随"。

**卦序关系：** 第17卦，前为**豫卦**（第16卦，安乐之后必思进取，进而有所随），后为**蛊卦**（第18卦，跟随久了必生弊端，须整治）。体现了"乐极思随，随久生弊"的递进关系。
