# 周易第12卦：否卦（天地否）

---

## 1. 卦名与卦象
- **卦名**：否（pǐ）
- **卦象**：上☰乾（天），下☷坤（地）
- **卦符**：
```
▅▅▅▅  上九
▅▅▅▅  九五
▅▅▅▅  九四
▅▅ ▅▅  六三
▅▅ ▅▅  六二
▅▅ ▅▅  初六
```

## 2. 卦辞
**原文**：否之匪人，不利君子贞。大往小来。
**白话解释**：否卦象征闭塞不通，天地不交，万物不生。此时小人道长，君子道消，不利于坚守正道。大的（阳气）向外离去，小的（阴气）向内来到。

## 3. 六爻爻辞

| 爻位 | 原文 | 白话解释 |
|------|------|----------|
| **初六** | 拔茅茹，以其汇，贞吉，亨。 | 拔起茅草会带出同类根系，比喻小人互相勾结。此时宜守正道则可亨通。 |
| **六二** | 包承，小人吉，大人否，亨。 | 包容顺承，对小人看似吉祥，但大人处否境仍能亨通（因守正道）。 |
| **六三** | 包羞。 | 包藏着羞耻，比喻处境难堪，需谨慎忍耐。 |
| **九四** | 有命无咎，畴离祉。 | 顺应天命行事则无灾祸，同享福祉。否极泰来的开始。 |
| **九五** | 休否，大人吉。其亡其亡，系于苞桑。 | 止住闭塞局面，大人吉利。时刻警惕危亡，才能稳固如苞桑。 |
| **上九** | 倾否，先否后喜。 | 否极泰来，先经历闭塞，最终迎来喜庆。 |

## 4. 整体简要解释
否卦与泰卦相对，象征**闭塞不通、阴阳隔绝**的时期。天地不交则万物不生，社会上下不通则小人得势。卦中提示：
- 短期不利，但否极必泰来
- 君子宜韬光养晦，守正待机
- 九五爻为转折点，可逐步打破闭塞

## 5. 现代应用建议
1. **人际关系**：若沟通受阻，避免强行突破，可暂时保持距离，等待时机。
2. **事业发展**：行业或组织出现闭塞时，不宜冒进，可优化内部结构（如“拔茅汇类”）。
3. **个人成长**：遇到瓶颈期，可视为沉淀机会，通过学习积累实力。
4. **决策智慧**：参考“休否”“倾否”思路，在低谷中主动寻找破局点，同时保持危机意识。
