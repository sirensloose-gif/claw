# 《周易》第二十七卦：颐卦 (山雷颐)

## 1. 卦名与卦象

*   **卦名**：颐 (yí)
*   **卦象**：上卦为 **艮**（山），下卦为 **震**（雷）。卦形如同一张张开的嘴，上下两阳爻为嘴唇，中间四个阴爻为牙齿。
*   **象曰**：山下有雷，颐。君子以慎言语，节饮食。
    *   **白话**：山下有雷在震动，象征着口腔咀嚼、颐养之象。君子由此悟得，应当言语谨慎（祸从口出），饮食有节（病从口入），修养身心。

## 2. 卦辞

*   **原文**：颐。贞吉。观颐，自求口实。
*   **白话解释**：颐卦象征颐养。坚守正道可得吉祥。观察万物如何被滋养（观颐），同时也要自己寻求滋养身心的真正内容（自求口实）。这里强调的“颐养”不仅是口腹之欲，更包括精神、品德的滋养。

## 3. 六爻爻辞

| 爻位 | 爻辞（原文）                 | 白话解释                                                                                             |
| :--- | :--------------------------- | :--------------------------------------------------------------------------------------------------- |
| **初九** | 舍尔灵龟，观我朵颐，凶。     | 放弃你灵龟（象征智慧、长寿）般的高明，却羡慕我口中咀嚼的食物（比喻物质欲望）。这样做有凶险。           |
| **六二** | 颠颐，拂经于丘颐，征凶。     | 颠倒向下求养，违背常理去向高处（如权贵）求养，若前往则有凶险。应靠自身努力。                         |
| **六三** | 拂颐，贞凶。十年勿用，无攸利。 | 违背了颐养的正道，即使坚持也有凶险。很长时间（十年）内都不可用，没有什么利益。                       |
| **六四** | 颠颐，吉。虎视眈眈，其欲逐逐，无咎。 | 向下求养（比如亲近百姓、学习底层智慧），吉祥。像老虎一样目光专注、威严，欲望专一（如捕食般专注），没有灾祸。 |
| **六五** | 拂经，居贞吉，不可涉大川。   | 虽偏离常理（指居于尊位却需求养于人），但安居守正则吉祥。不可冒险（如渡大河）。                       |
| **上九** | 由颐，厉吉，利涉大川。       | 由他（上九）来滋养万物（众阴爻），虽然有危险但终获吉祥，利于渡过大河（成就大事）。                   |

## 4. 整体简要解释

颐卦的核心是 **“颐养”**。它从卦象上描绘了一张嘴，并引申出三层含义：

1.  **养身**：最基本的口腹之养。提醒我们饮食要健康、有节制。
2.  **养德**：更深层次的精神滋养。要通过学习、思考、与良师益友交往来滋养心性、增长智慧。
3.  **养人**：对于居于上位者（如领导、长辈），颐卦关乎如何正确地“养育”和教导他人。

卦辞强调“观颐”和“自求口实”，即观察和学习正确的滋养之道，并依靠自己的努力去实践。全卦告诫人们：求养必须坚守正道（贞），不可贪求不正当的滋养（如初九、六二、六三），要靠自强和正确的方法（六四、上九）。

## 5. 现代应用建议

1.  **身心健康**：关注自己的饮食结构和作息规律。不要暴饮暴食，也不可过度节食。同时，重视心理健康，通过阅读、艺术、冥想等方式滋养心灵。
2.  **学习与成长**：把“颐”理解为终身学习。像“自求口实”一样，主动寻找有价值的知识、技能和人生智慧来充实自己，避免精神上的“营养不良”。
3.  **人际关系**：在给予他人（如子女、下属、朋友）帮助或建议时，要提供真正有益、正确的东西（“观颐”的智慧），而不是溺爱或灌输错误观念。
4.  **领导与管理**：为团队或组织提供正确的方向、资源和培养（“由颐”），要有“虎视眈眈”的专注力和责任感，同时保持谦逊，向下了解实际情况（六四颠颐）。
5.  **投资与决策**：在寻求资源或合作时（“自求口实”），要考察对象的本质是否健康、正向（如同观察“灵龟”），避免被表面的诱惑（“朵颐”）所迷惑，做出短视的决定。

**核心箴言**：**真正的“颐养”，是内外兼修，滋养有道，节制有度。**
