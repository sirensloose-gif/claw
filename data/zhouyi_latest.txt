# 周易第6卦 · 讼卦 ☰水天 ☯（天水讼）

---

## 一、卦名与卦象

| 项目 | 内容 |
|------|------|
| **卦名** | 讼（sòng） |
| **卦象** | 上卦为**乾**（天），下卦为**坎**（水）→ **天水讼** |
| **卦序** | 第6卦，属"上经" |
| **象征** | 争讼、诉讼、冲突、纠纷 |
| **核心意象** | 天在上，水在下，方向相背——**上刚下险**，天理与险陷相违，故生争端 |

> 📖 **记忆口诀**：天刚而健，水险而下，二气相违，讼端由此。

---

## 二、卦辞（原文与白话）

### 📜 原文
> **"讼，有孚，窒惕，中吉，终凶。利见大人，不利涉大川。"**

### 💡 白话解释
争讼之时，若心怀诚信（有孚），则能克制恐惧（窒惕）。**适中而止**则吉，**穷追到底**则凶。此时**有利于面见大人**（寻求公正裁断），**不宜冒险涉过大川**（不宜贸然行动）。

### 🔑 关键词拆解
| 词语 | 含义 |
|------|------|
| **有孚** | 内心诚实、有凭据 |
| **窒** | 克制、压抑 |
| **惕** | 警惕、畏惧 |
| **中吉** | 适中而止则吉 |
| **终凶** | 穷究到底则凶 |
| **利见大人** | 有利寻找公正之人裁决 |
| **不利涉大川** | 不宜冒险犯难 |

## 三、六爻爻辞（逐爻详解）

### ☰ 初六 — 不永所事
**原文：**
> "不永所事，小有言，终吉。"

**白话：**
争讼之事不要长久纠缠不休。虽会有些许言语纷争（小有言），但最终能化险为夷，结局是吉祥的。

**💡 寓意：** 争端初起时，不要拖泥带水、不依不饶，小事忍让，最终获吉。

---

### ☰ 九二 — 不克讼
**原文：**
> "不克讼，归而逋，其邑人三百户无眚。"

**白话：**
争讼无法获胜（不克讼），便退避归隐。如此则自己所居的三百户人家都不会遭受灾祸（无眚）。

**💡 寓意：** 争不过就知进退，果断撤退，反而能保护自己和周围的人免受牵连。

---

### ☰ 六三 — 食旧德
**原文：**
> "食旧德，贞厉，终吉。或从王事，无成。"

**白话：**
守住已有的旧德，持守正道虽有危险（贞厉），但最终吉祥。若顺从王命办事，则不会有大成。

**💡 寓意：** 守本分、不越界，不贪功冒进，守住原有的根基就是最好的策略。

---

### ☰ 九四 — 不克讼，复即命
**原文：**
> "不克讼，复即命，渝安贞吉。"

**白话：**
争讼无法获胜（不克讼），便回归天命（复即命）。改变主意（渝），安守正道（安贞），则吉祥。

**💡 寓意：** 争不赢就回头审视天命，转变态度，安分守正，终得吉祥。**知退即进**的智慧。

---

### ☰ 九五 — 讼元吉
**原文：**
> "讼元吉。"

**白话：**
争讼而能公正断理，至为吉祥（元吉）。

**💡 寓意：** 九五爻位为君位，居中且正。以公正之心裁断争端，则讼卦反成大吉。**说明争讼不可怕，关键在于裁断公正。**

---

### ☰ 上九 — 或锡之鞶带
**原文：**
> "或锡之鞶带，终朝三褫之。"

**白话：**
或者因争讼而获得赏赐的官印绶带（鞶带），但一个早晨内就被三次剥夺（三褫之）。

**💡 寓意：** 靠争讼得来的名利如同过眼云烟，得而复失，转瞬即逝。**告诫不可用不正当手段去争名夺利。**

---

## 四、整体简要解释

### 🧩 卦意核心

**讼卦**探讨的是**争讼与冲突**的主题。

1. **上卦乾为天**，刚健而外；
2. **下卦坎为水**，险陷而内；
3. 天理与险陷相违，上下背离，矛盾由此产生。

### 📊 讼卦的核心思想

```
┌──────────────────────────────────────────┐
│           讼卦的智慧脉络                  │
├──────────────────────────────────────────┤
│                                          │
│  ① 有争端时 → 心怀诚信（有孚）           │
│  ② 争讼中   → 适可而止，不宜穷究         │
│  ③ 不利冒险 → 宜求公正大人裁断           │
│  ④ 争不过   → 知退则退，保全自身         │
│  ⑤ 裁断公正 → 反而至为吉祥               │
│  ⑥ 争得利益 → 终将得而复失，不可恃也     │
│                                          │
└──────────────────────────────────────────┘
```

### 🎯 六爻的变化趋势

> **初爻**（忍让退让）→ **二爻**（知难而退）→ **三爻**（守旧安分）
> → **四爻**（回归天命）→ **五爻**（公正断案，元吉）→ **上爻**（得而复失）

从**小争端**到**大冲突**，最终证明：**真正的大吉在于公正**，而非争斗本身。

## 五、现代应用建议

### 💼 职场与商业

| 场景 | 建议 |
|------|------|
| **合同纠纷** | 不宜纠缠不休（初六），应寻求法律仲裁而非私斗 |
| **商业竞争** | 知进退（九二），竞争不过时撤退，保存实力 |
| **利益分配** | 守住本分（六三），不贪不抢，守住原有份额 |
| **谈判僵局** | 转变态度（九四），换一个思路往往柳暗花明 |
| **仲裁决策** | 以公正为核心（九五），不偏不倚裁断，反得信任 |
| **投机取利** | 警惕不义之财（上九），靠争斗得来的利益终将失去 |

### 👥 人际关系

- **冲突初起**：不小事化大，冷处理比热对抗有效
- **争不过**：主动退一步，关系反而更好
- **守好本分**：不越界、不贪婪，关系稳固
- **改变策略**：当一条路走不通，果断换方向
- **做公正的裁判**：如果朋友间有矛盾，不偏袒任何一方
- **不恃强凌弱**：靠霸道争来的优势，终会被反噬
